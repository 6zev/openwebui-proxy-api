Kết nối API

Tương thích OpenAI, dùng chung một khoá proxy.

Header định tuyến 
Authorization: Bearer <PROXY_API_KEY>
X-Website-ID: <website_id>
X-Account-ID: <account_id>  # tuỳ chọn

Bỏ X-Account-ID để proxy tự chọn tài khoản còn sẵn sàng trong website.
